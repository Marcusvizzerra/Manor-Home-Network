NETWORK OVERVIEW :::
AT&T fiber terminates at the BGW320-505, which acts as the primary gateway and Wi-Fi 6 (802.11ax) access point. 
High-bandwidth clients stay on this network: the PS5 and PS4 are hardwired (CAT5) for consistent low-latency performance, while the Xbox Series X and both Samsung displays run wireless on the 5 GHz radio.
IoT and security devices are segmented onto a secondary ASUS RT-N router, uplinked LAN-to-WAN from the BGW320. This keeps the 2.4 GHz-only devices (Ryobi garage door, Wyze cameras) on their own broadcast domain so they don’t contend with gaming/media traffic or expand the attack surface of the main network. 
Wireless links are dashed, wired are solid.
